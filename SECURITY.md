# Security Policy

## Report a vulnerability

Please do not report suspected security vulnerabilities in public GitHub issues.

Submit a private report through GitHub's vulnerability reporting form:
https://github.com/tahawinner25-ai/PBOS/security/advisories/new

GitHub sign-in may be required. If the form is unavailable, check the deployed site's `/.well-known/security.txt` for a private contact method. The security.txt route publishes a contact only when `NEXT_PUBLIC_CONTACT_EMAIL` is configured; otherwise it returns 404. Do not share exploit details publicly while seeking a private reporting channel.

When reporting, include the affected page or component, the relevant commit or version if known, concise reproduction steps, and the potential impact. Use a minimal proof of concept. Do not include real user data, credentials, API keys, or access tokens, and test only systems you own or are authorized to assess.
